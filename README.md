# ViTune Classic

A work-in-progress fork of [ViTune](https://github.com/bartoostveen/ViTune), inspired by the classic Android Material Design aesthetic of 2015–2017.

Project branding, screenshots, installation instructions, and feature documentation will be updated as development progresses.
